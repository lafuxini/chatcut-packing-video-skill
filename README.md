# 打包视频丝滑精剪 · ChatCut/Codex Skill

这是一个公开、可复用的 Codex Skill，用来指导 ChatCut 完整而紧凑地剪辑打包、装盒、贴纸与手账类视频。

## 最省事的使用方式

请在 **ChatGPT/Codex 桌面版**中新建任务，把下面整段发给 Codex：

```text
/goal 请先按照 https://chatcut.io/chatgpt 安装并连接官方 ChatCut 插件；再从 https://github.com/lafuxini/chatcut-packing-video-skill 安装其中的 chatcut-packing-video-skill。完成授权后新建一个剪辑任务，使用“打包视频丝滑精剪”Skill，等待我提供原始素材和参考片。不要使用网页版云导出，默认通过 ChatCut Desktop 或本机导出。
```

首次使用时，使用者必须在 ChatCut 打开的官方授权页登录自己的账号并允许连接。不要在聊天里发送密码、Cookie 或访问令牌。插件工具会在新任务启动时加载，因此安装后要进入新任务再开始剪辑。

## 两个来源

- 官方 ChatCut 插件安装说明：https://chatcut.io/chatgpt
- 本剪辑 Skill：https://github.com/lafuxini/chatcut-packing-video-skill

## 这个 Skill 会做什么

- 保留每个独特的放置、撕贴、整理、合盖和装饰动作。
- 删除寻找、准备、停顿与放稳后的多余停留。
- 主体按动作复杂度使用约 1.5–1.7 倍速。
- 使用柔和粉嫩调色、背景降噪和适度扩音。
- 默认不加字幕、音乐、复杂转场或人工侧边。
- 要求在导出前检查后半段动作是否完整，并优先本地导出。

核心规则仍可直接查看根目录的 [SKILL.md](SKILL.md) 与 [质量检查清单](references/quality-checklist.md)。
